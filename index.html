Console Syntax Documentation & Commands

Command Syntax Manual

Aplikasi ini mendukung parsing perintah syntax ala lighting console profesional:


Fixture Selection:

Fixture 1 - Selects fixture 1

Fixture 1 Thru 6 - Selects fixtures 1 to 6

Clear - Clears active selection & programmer


Attribute Control:

At 100 / Dimmer 100 - Sets dimmer to 100%

Full - Shortcut for At 100

Zero - Shortcut for At 0

Color Red / Color Blue / Color Green - Changes color

Pan 45 / Tilt -30 - Adjusts fixture position


Cue & Playback System:

Store Cue 1 - Stores programmer state into Cue 1

Go - Triggers next active Cue

Effect "Circle" - Applies P/T Circle engine

Wing Open - Applies symmetrical wing structure


3D Viewport Controls:

W A S D / Arrow Keys - Move camera position

Q / E - Elevate camera Down / Up

Mouse Drag - Orbit 3D stage view

Mouse Wheel - Camera Zoom
